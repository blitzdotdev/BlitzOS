Building blocks for your agent workforce.

BlitzOS is infrastructure to build your agent workforce. Each agent gets a workspace: its own VM, credentials, and data. Agents can also spawn workspaces for their subagents. Create and manage them all from our open-source web and mobile apps. BYO agents and machines.

01

Agent Workspaces

Agent workspaces are the core primitive of BlitzOS. A workspace is a Linux VM with persistent storage, running any number of agents. Run it on our cloud machines or your cloud account.

The machine · disposable
Agents run here. Our cloud, yours, or any provider's.
The volume · durable
Repos, files, secrets, and sessions live here.
Attach / re-attach to any machine.

The machine

  • Any provider's VM, or your own box. Claude Code, Codex, OpenCode, Pi, and Kimi Code preinstalled.

The volume

  • Your repositories, files, and agent sessions live on provider-backed persistent storage.
  • The volume survives machine replacement and workspace deletion.

Secrets

  • Connect services through the secret broker. BlitzOS enforces agent access controls and supports approval for escalated access.
  • The secret broker logs every agent request and approval for you to audit.

Sessions

  • Agent sessions persist on workspace storage. Sessions survive tab closes and machine replacement.
02

Working with agent workspaces

  • The Blitz app: manage agent workspaces from the web or mobile app, or self-host it. The Blitz app is open-source and designed to be modified.
  • Agent API: agents can create agent workspaces through our API. For example, any agent can spawn subagents with their own workspace, giving them the required machine, secrets, and data in one POST call.
main agent
POST /api/v1/workspaces × 3
the right machine · secrets · data — per subagent
03

Vibe-coded apps

Using our API, agents can create and deploy full-stack web apps. Backed with a real database & file storage and served on Cloudflare edge, these apps can replace entire SaaS subscriptions, and can be shared with your team just like a google doc.
