版本 0.82.0

### ✨ 新功能

- 支持在本地项目中使用 Git 流程；授权 Lody GitHub 集成后，也可使用 GitHub PR 工作流。
- 支持拖拽 sidebar 的 session 到输入框自动 @ mention。
- 支持将会话分叉到新的 worktree，便于并行推进不同方案。
- 新增全局 MCP 配置，创建对话时可在加号按钮菜单中选择。
- 输入框中的 @ 提及现以标签形式展示，支持更方便地引用会话和技能。
- 可在差异文件标题中直接复制路径或打开文件。
- 新增使用量趋势视图，可按时间范围查看使用情况。
- 现在支持订阅和兑换码同时生效。

### 🐛 修复与改进

- 改善流式对话的滚动跟随、终端复制粘贴与文本选择体验。
- 改善子会话关系的展示与跳转，并优化移动端的层级列表。
- 修复工作区回收、会话启动和连接恢复中的若干稳定性问题。
- 优化侧边栏与页面导航性能，减少不必要的界面刷新。
