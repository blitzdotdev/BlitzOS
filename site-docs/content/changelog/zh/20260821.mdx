版本 0.84.0

### ✨ 新功能

- 新增桌端会话轮次导航，可快速浏览和跳转长会话中的不同轮次。
- 新增 Google Antigravity 支持，并更新多款 ACP 编程智能体。

### 🐛 修复与改进

- 改进 Codex 历史会话导入，避免在查看历史记录时意外恢复旧线程。
- 修复 Windows 上 Kimi 和其他 ACP 智能体执行命令及工具时的路径和参数问题。
- 优化窄窗口下的偏好设置布局、首次设置状态提示和 macOS Dock 图标显示。
- 修复官网浅色模式显示和部分浏览器中的启动异常。
