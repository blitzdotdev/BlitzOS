版本 0.85.0

### ✨ 新功能

- 新增系统主题模式，可跟随设备的浅色或深色外观。
- DeepSeek Harness 智能体新增图片输入支持。

### 🐛 修复与改进

- 修复使用输入法时按 Esc 可能导致焦点丢失的问题。
- 改进会话提及的拖放交互。
- 确保 Grok 的权限设置在新建和恢复会话时正确生效。
- 改进 DeepSeek Harness 的启动兼容性与稳定性。
