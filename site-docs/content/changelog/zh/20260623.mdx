版本 0.63.0

### ✨ 新功能

- 新增 `lody review` 本地代码审查工具，无需登录即可查看审查报告
- 会话支持发送任意类型文件附件，可预览，Agent 也能读取和回传文件
- 全新命令面板(⌘K)：一处搜索命令、快速切换会话
- 键盘快捷键设置页：所有快捷键可自定义、重绑、检测冲突
- 桌面端快速新建会话窗口(⌘⇧N)，全键盘操作
- 桌面终端主题跟随 App，底部状态栏改为 VSCode 风格
- 会话"在…中打开"新增 Xcode、Sublime 及自定义启动器
- 输入框可用 `$` 提及项目 Skill，并新增 Skills 查看页
- 可删除其他设备上的本地项目
- 新增对话字体大小设置
- 新增 DeepSeek Reasonix Provider
- 桌面端可关闭 CLI 自动启动，纯做远程控制端

### 🐛 修复与改进

- 优化 All Changes 列表显示速度
- PR 新增"草稿"状态徽标
- 图片文件上传，对话界面均可以响应
- worktree 脚本新增缓存，避免等待加载
- 修复回复 AI 提问时，输入法键盘遮挡问题
- 优化移动端模型过长的显示问题
- 减少流式输出时的卡顿与发热
- 修复 macOS 下 Cmd+W 全屏变黑屏
- 修复侧边栏选中高亮边框被裁剪、时间戳前多余空白
- 会话搜索快捷键在 macOS 上改为 ⌘F
- 移动端模型选择器长名称更易读，弹层不再被键盘遮挡
- 用户手动停止任务后不再误发"已完成"通知
