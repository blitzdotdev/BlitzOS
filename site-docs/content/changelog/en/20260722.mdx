### New

- Upgraded the local-first architecture. Desktop can now start, browse, and continue using existing local projects and sessions even when offline.
- Local conversations can preview web pages directly in Design mode without setting up a tunnel.
- Added Agent-powered controls for creating, reading, and managing other Lody conversations.
- Added built-in support for the Kimi Code provider.
- Improved conversation initialization speed, especially for local projects.
- Improved the GitHub project UI and UX, with expanded actions in the conversation action bar.
- Added customizable interface and terminal fonts.

### Fixes and Improvements

- Improved usage chart presentation.
- Fixed local sessions getting stuck, repeatedly reconnecting, or remaining in a thinking state during offline use, weak connections, and network recovery.
- Fixed login sessions that could expire after Lody had been left running for a long time.
- Fixed undo and redo in the composer occasionally not working.
- Refined the overall interface and user experience.
