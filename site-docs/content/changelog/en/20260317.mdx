### New Features and Capabilities

- Official release of the desktop app, available [here](/download)
- Added image input support and screenshot responses
<img src="/_docs-assets/20260317-lody-image-back.png" alt="" />
- Added support for all ACP Registry configuration options
- Added a full [CLI command set](/docs/cli): `session`, `workspace`, `history`, `agent-config`, and `machine`

### Platform and UI Experience

- Show group counts when the sidebar is collapsed, and display PR numbers directly on PR sessions
- Added desktop version display and update checks
- Added a Restart CLI button
- Prevent system sleep while sessions are running, with a setting to disable it
- Remember desktop window size and position

### Fixes and Stability

- Fixed an issue where token usage could show negative deltas
- Fixed inflated change counts in the Changes tab
- Fixed issues with mobile orientation changes, scrolling on the Settings and Integrations pages, and the close button position in image previews
