### New

- From a remote device you can now inspect the Git branches of a local project and start a worktree directly.

### Fixes and Improvements

- Fixed incorrect avatars for sessions imported from external ACP agents.
- Fixed Claude sessions occasionally getting stuck in an idle state.
- Fixed wrong ordering in slash command search results.
- Fixed session history imports occasionally producing duplicate entries.
- Fixed an unexpected redirect during email login in the mobile app.
